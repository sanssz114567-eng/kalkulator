kalkulator Sederhana PythonAplikasi CLI (Command Line Interface) berbasis Python untuk melakukan operasi matematika dasar.Program ini dirancang sederhana agar mudah dipahami oleh pemula.

🚀 Fitur

Penjumlahan(+): Menambahkan dua angka.

Pengurangan (-): Mengurangi angka pertama dengan angka kedua.

Perkalian (*): Mengalikan dua angka.

Pembagian (/): Membagi dua angka dengan validasi anti-error jika pembagi adalah nol (0).

🛠️ PrasyaratSebelum menjalankan program ini, pastikan Anda sudah menginstal:Python 3.x di komputer Anda.

💻 Cara Menjalankan

Salin kode kalkulator ke dalam file baru dan beri nama kalkulator.py.

Buka terminal atau command prompt.

Jalankan perintah berikut:bash
